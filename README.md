## 🚀 Project Overview

An end-to-end smart home energy optimization system combining:

- 📱 Mobile App (Flutter)
- 🧠 Machine Learning (Random Forest)
- ⚙️ Backend API (FastAPI)

Designed to analyze energy usage, predict future consumption, and provide intelligent recommendations for energy saving.

---

## 📊 Results & Impact

- Achieved **R² score of 0.96** in energy consumption prediction  
- Improved performance with effective **feature engineering**  
- Enabled intelligent recommendations based on real usage patterns  
- Demonstrates real-world impact of AI in energy optimization  

> This project showcases the integration of data analysis, machine learning, and user-centered application design.

## 🔐 Security & Configuration

- Sensitive data (API keys, configs) managed via **.env**  
- No secrets are included in the repository  
- Backend is designed for **local development environment**  

> Follows basic security practices by separating configuration from source code.
